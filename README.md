# MAEVEN

A minimalist Vietnamese menswear brand site and its lifestyle magazine, built from
the `Maeven A.dc.html` design canvas.

Next.js 16 (App Router) · React 19 · Tailwind CSS v4 · TypeScript.

## Running

```bash
npm run dev      # http://localhost:3000
npm run build
npm start
npm run lint
```

## Routes

| Route | Page |
|---|---|
| `/` | Trang chủ — hero, marquee, mới về, tạp chí, cam kết |
| `/product` | Cửa hàng — cả bộ SS26 |
| `/product/[sku]` | Chi tiết sản phẩm — gallery, kích cỡ, thông số (4 mẫu) |
| `/magazine` | Tạp chí — lọc theo chuyên mục |
| `/article/[slug]` | Bài viết — tóm tắt AI, VI/EN, đọc tiếp (7 bài) |
| `/about-us` | Giới thiệu — định vị, bốn xưởng, cam kết, vai trò của AI |
| `/credits` | Tín dụng ảnh — Pexels attribution |

Every card leads to a real page: all four products and all seven articles are
written out in full. Adding one means adding it to `ARTICLES` or `PRODUCTS` in
`src/lib/data.ts` — `generateStaticParams` derives the routes from those arrays.

The VI/EN toggle appears only on articles that have an `en` body written, so the
control is never offered where it would do nothing.

## Layout

```
.claude/agents/             Project agents — see .claude/README.md
design/                     Source canvas — Maeven A.dc.html + support.js (read-only reference)
design.md                   Brand identity: palette, type, lockups, voice
scripts/fetch-images.mjs    Pexels fetcher; manifest at top of file
src/app/                    Routes, one folder per page
src/components/             SiteHeader, SiteFooter, Photo, Marquee, ArticleCard, ProductCard, Prose
src/lib/data.ts             All copy — products, articles (VI/EN bodies), promises
src/lib/photo-credits.json  Generated by the fetcher — photographer + source per image
public/img/                 Downloaded photography
```

## Design tokens

Brand identity — palette, typography, logo lockups and voice — is documented in
[`design.md`](design.md). The tokens live as Tailwind v4 `@theme` variables in
`src/app/globals.css` and are used as normal utilities (`bg-ink`, `text-forest`,
`border-line`, `font-display`, `animate-marquee`), plus three component classes:
`.mono-label`, `.hatch`, `.hatch-dark`.

## Responsive

Mobile-first throughout. Containers are `px-4 sm:px-6`; grids step
`grid-cols-1 → sm:grid-cols-2 → lg:grid-cols-3/4` rather than using `auto-fit`
minimums that can overflow a 320px viewport. The header shows the full tab row at
`md` and up, and a hamburger drawer below it. The magazine's rubric filter scrolls
sideways on a phone instead of wrapping into four rows.

## Images

Photography is fetched from the Pexels API:

```bash
npm run fetch:images                  # idempotent — skips files already present
node scripts/fetch-images.mjs --force # re-fetch everything
node scripts/fetch-images.mjs brand/  # re-fetch one prefix
```

Needs `PEXELS_API_KEY` in `.env.local` (gitignored). The manifest — path, query,
orientation, target ratio — is the array at the top of the script; edit it there
and re-run. Every fetch rewrites `src/lib/photo-credits.json`, which drives
`/credits`; the Pexels license requires that attribution stay in place.

Two notes from the fetch: Pexels' landscape bucket is overwhelmingly 3:2, so
`article/hero.jpg` is CSS-cropped to 16:9 rather than natively that ratio, and
`brand/hero.jpg` is a studio-lit portrait that reads harsher than the brand's
natural-light direction — re-query it if it bothers you.

## Looking at it

`scripts/shoot.mjs` screenshots the running site so visual changes can actually be
reviewed. It drives the installed Chrome through Playwright — Playwright cannot
download a browser on macOS 12, hence `channel: "chrome"`.

```bash
npm run build && npm start          # or next start -p 3131
npm run shoot                       # every preset -> shots/
node scripts/shoot.mjs hero --wait 4500
node scripts/shoot.mjs hero --reduced      # reduced-motion path
node scripts/shoot.mjs hero --mobile       # 390x844
node scripts/shoot.mjs cards --hover ".group"
```

It reports whether a live WebGL canvas exists on the page and prints any console
errors. `shots/` is gitignored.

## Agents

`.claude/` holds eleven project agents and three skills:

- **preflight** — boots the site and checks every route, image and motion mode
- **frontend-doctor** — finds and fixes frontend defects
- **photo-scout** — sources photography from Pexels
- **content-model** — owns the shape of the typed content layer
- **magazine-writer** — writes and installs new articles
- **blog-reviewer** — editorial quality gate against the `design.md` voice contract
- **blog-seo** — on-page SEO validation for the Next.js metadata surface
- **responsive-auditor**, **a11y-auditor**, **design-system-guard** — read-only reports

Skills: `/blog-schema` (JSON-LD), `/blog-factcheck` (fiction-aware claim check),
`/blog-translate` (VI → EN). Five of these are adapted from
[`AgriciDaniel/claude-blog`](https://github.com/AgriciDaniel/claude-blog) under MIT
— see [`.claude/NOTICE.md`](.claude/NOTICE.md).

See [`.claude/README.md`](.claude/README.md).
